# PetCare 🐾

PetCare — это веб-приложение для хранения информации о домашних питомцах.

## Возможности

- Профиль питомца
- Календарь событий
- Вакцинация
- Обработка от глистов
- Обработка от блох и клещей
- Дневник питомца
- Вес и графики
- Загрузка фотографий
- Напоминания

## Технологии

- FastAPI
- PostgreSQL
- React
- Docker
- Nginx
- GitHub Actions
- Yandex Cloud
